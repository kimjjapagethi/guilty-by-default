# Guilty by Default — 전시/웹 게임 (v3)

3명(유족 / 피자 가게 사장 / 대통령) 중 한 명이 되어 약 5분을 플레이합니다.
오프닝 → 도입 → **입장 카드**(처한 상황·할 수 있는 것·닿지 않는 것·영향력) → 마주침 → 반전 → **CHOICE 01**(회복 M · 진실 T · 미래 P) → 즉시 반응 → 청문회 → **CHOICE 02**(AI · 인간 · 공동) → 판결 → 엔딩(E1~E5) → 마지막 질문.
엔딩: M+AI=E1, T+인간=E2, P+공동=E3, T+(AI|공동)=E4, 나머지=E5.

## 실행 (Windows 포함)
```
npm run dev
```
→ 게임 http://localhost:3000 · 옆 화면 http://localhost:3000/side · 디자인 시스템 http://localhost:3000/design
(포트 변경: PowerShell `$env:PORT=3100; npm run dev`)

주소 옵션: `?kiosk=1` 90초 무입력 시 처음으로 · `?test=1` 통계에서 제외
조작: 키보드 `1` `2` `3` 선택, `Enter`/`Space`/클릭 다음 (하드웨어 버튼은 이 키에 매핑하면 됩니다)

## 스크립트 편집기 (코드 안 건드리고 대사 고치기)
`npm run dev` 후 **http://localhost:3000/editor**
- 왼쪽 목록에서 컷을 고르면: 말한 사람 · 대사(줄바꿈은 Enter) · 종류(대사/내레이션/AI/강조) · **자동 넘김 ms**(0이면 누를 때 넘어감) · 컷 번호 · 스토리보드 설명 · 이미지 파일(올리기) · 자막 위치 · 처음 이미지만 보여주는 시간 · 프로필 카드를 바꿀 수 있고, 오른쪽에서 바로 미리 봅니다.
- 컷 순서 바꾸기·복제·삭제, 대사 줄 추가·삭제·순서 바꾸기, 선택지·엔딩·거울 문장도 편집됩니다.
- **저장**을 누르면 `public/script.json`에 써지고 게임을 새로고침하면 바로 반영됩니다(직전 것은 `script.prev.json`으로 남음). 처음 상태는 `script.default.json`.
- 저장은 localhost(전시 PC, MODE=exhibit)에서만 됩니다. 웹 공개 모드에서는 막혀 있습니다.

## 파일
| 파일 | 역할 |
|---|---|
| `public/ds.css` | 디자인 시스템 (색·서체·자막 토큰). **수정하지 않았습니다** |
| `public/game.css` | 게임 화면 스타일 (ds.css 토큰만 사용) |
| `public/game.js` | 게임 흐름·규칙 (근거 약함, 엔딩 매핑) |
| `public/script.json` | **모든 대사·선택지·엔딩 (편집기가 이 파일을 씁니다)** |
| `public/editor.html` | 스크립트 편집기 |
| `public/index.html` | 게임 진입 |
| `public/side.html` | 옆 화면 (인물별 인원, 엔딩 분포) |
| `server.js` | 저장·통계 (의존성 없음). 기록: `data/plays2-<mode>.jsonl` |
| `public/_old/` | 이전 게임 파일과 옛 데이터. 삭제하지 않고 보관 |

## 이미지 넣기
편집기에서 컷마다 올리거나, `public/scenes/<컷번호>.webp|png|jpg` 로 넣으면 자동으로 보입니다. 이미지는 화면 전체(cover)에 깔리고 자막·카드는 16:9 안쪽에 놓입니다.

## 기록 스키마 (`/api/play`)
`{ sid, src, test, ch(0~2), mc(항상 0), c1(0~2), c2(0~2), weak, ending('E1'~'E5') }`
통계는 20판 이상 모이기 전엔 퍼센트를 공개하지 않습니다(인원수만). 이전 게임 기록 `plays-*.jsonl` 은 읽지 않고 그대로 남아 있습니다.

## 메모
- 선택지에는 '얻는 것/잃는 것/대가/범위/영향력'을 보여주지 않습니다. 결과는 선택 뒤 컷(영향 · … 문장)에서 보여줍니다.
- 근거 약함 규칙: 첫 선택이 회복(M)이면 '인간', 진실(T)이면 'AI', 미래(P)이면 '공동' 외 둘이 약함 → 선택 2 첫 대사 뒤에 '근거가 부족하다' 문구만 추가(엔딩은 안 바뀜).
