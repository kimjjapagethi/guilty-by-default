외부 패키지가 없습니다. Node.js 18 이상만 있으면 됩니다. (`npm install` 불필요)

## 실행
    MODE=exhibit PORT=3000 ADMIN_TOKEN=원하는암호 node server.js      # 전시장 PC
    MODE=web     PORT=3000 ADMIN_TOKEN=원하는암호 node server.js      # 인터넷에 올리는 웹 버전
(윈도우 PowerShell: `$env:MODE="exhibit"; $env:ADMIN_TOKEN="암호"; node server.js`)

| 주소 | 내용 |

## 게임 흐름 (v9, 챕터 형식)
0 대기 → 경고 → 인트로 →
**Chapter 1. 낙원**(챕터 전환: 암전 → 제목): 나레이션(2030, 생각하는 망치) → 질문 [낙원이다/불쾌하다] → 사고 나레이션 → 의료진·AI 대사 → 조사 위원회 질문(세 선택지를 모두 본 뒤 진행) → 책임의 공백 나레이션 → 암전
**Chapter 2. 귀책, 누구의 탓인가?**
**2부 귀책**: `public/part2.html`(iframe, 1600×900, **마우스만**). 병동 전체 화면 → AI(오른쪽→왼쪽)·요원(아래→위) 등장 → 대사 → **수사 노트**(체포 요건 6개 질문)를 한 번 보여줌 → 인물 4명(유족·병원 관리자·침상 AI 단말·병동 서버) 호버/클릭.
  - 인물을 클릭하면 **그 인물이 확대**되고 우측 패널이 들어온다(대화 기록 유지). 질문은 인물당 1~2개, 클릭 한 번이면 답이 타자 치듯 한 글자씩 나오고 단서(조건)가 쌓인다. 총 6번 클릭이면 끝.
  - 좌상단 **수사 노트** 버튼: 6개 조건의 질문·확인할 곳·얻은 단서를 펼쳐 본다.
  - 6개가 모이면 요원의 결론과 함께 **마인드맵**(AI → 조건 6개, `다음으로` 버튼)이 펼쳐지고 → 중립 질문 “그렇다고 곧 AI의 잘못일까? 당신의 생각은?” [AI의 잘못이다 / AI의 잘못이라고 할 수는 없다] → `postMessage` `guilt`(yes/no) → **어떤 답이든 체포 장면**(요원 등장·붉은 띠·“체포” 도장) → `part2-next`.
  - 그래픽 교체: `public/part2/`에 `ward(전체 배경), agent, ai, family, manager, terminal, server`를 `.mp4/.webm/.png/.jpg/.webp`로 넣으면 자동 적용.
  - 대사·질문·조건은 `part2.html`의 `WHO` / `COND` 배열(현장 조사 인용으로 교체 예정).
**Chapter 3. 감당, 책임의 효과를 치르는가** (`public/part3.html`, 마우스): 체포 직후, **지금의 AI로** 사과·고치기·벌 3가지를 하나씩 집행한다(로그 한 줄 + AI의 담담한 대사 + “집행 ✓”). 사람이 치르는 값과의 비교나 설명은 넣지 않음. 3개를 마치면 → [감당했다/감당하지 못했다]. 4장 온톨로지에서 이 3가지(벌=응보, 고치기=교정, 사과=인정·신뢰회복)에 해당하는 현실의 시도를 보여준다.
**Chapter 4. 빈자리** (제목 임시): 귀책×감당(+첫 감정) 결합 결과 “당신은 이렇게 생각하고 있을지도 모릅니다” → **책임의 조건 12 × 책임의 효과 8 온톨로지**(`public/part4.html`: 조건/효과를 누르면 AI의 현재 수준(0~4 눈금), 확인된 것, 책임을 묻기 위한 시도(법인격 등), 아직 모르는 것, 출처, 2장 귀책 조건과의 겹침 표시; 하단 문장 “AI의 [조건]을 활용하거나 제한하여 [효과]라는 효과를 달성한다”; **4개 이상 눌러야 `다음으로` 활성화**, 전시 후 웹사이트에서 다시 볼 수 있다는 안내) → 비어 있는 자리 → [맡긴 걸 거둔다/책임질 AI를 만든다] → 결사의 입장+관람객 비율 → 크레딧
저장 항목: `feel`(ease/anx) · `guilt`·`burden`(yes/no) · `final`(withdraw/build). 옆 화면(`/side`)은 7단계 논증 지도를 진행 상황에 맞춰 밝혀 줍니다. (이전의 How to Play 단계는 흐름에서 뺐습니다.)

## 디자인 시스템
`public/ds.css` 한 파일에 색(버건디·페일 블루·아이보리), 서체, 크기, 컴포넌트, 모션이 모두 있습니다. 게임과 옆 화면이 같은 파일을 씁니다. 보기: `/design`

## 키보드(물리 버튼) 대응
- `1` = 왼쪽 선택지, `2` = 오른쪽 선택지 (모든 선택은 2지선다)
- `Enter` / `Space` = 다음 (아무 번호 키도 ‘다음’으로 동작)
- 대기 화면에서는 아무 키나 누르면 시작합니다. `?kiosk=1`이면 90초 동안 입력이 없을 때 처음(대기 화면)으로 돌아갑니다.
- 물리 버튼(왼쪽, 오른쪽, 다음)을 키보드 신호로 보내는 보드(아두이노 레오나르도, 라즈베리 파이 피코 등)가 필요합니다.

## 응답 저장·관리
- 끝까지 마친 판만 `data/plays-<mode>.jsonl` 에 익명으로 저장합니다(이름·기기 정보 없음, 무작위 세션 번호).
- 20명 미만이면 퍼센트 대신 “지금까지 N명”만 보여 줍니다.
- 관리(암호 필요): `/api/admin/export?token=암호` 내려받기 · `/api/admin/clear-test?token=암호` 테스트 응답 삭제 · `/api/admin/archive-reset?token=암호` 백업 후 초기화
- 서버가 꺼져 있어도 게임은 동작하며, 저장하지 못한 응답은 브라우저에 보관했다가 다시 보냅니다.

**part3/part4 연동**: `part3-done`(burden) / `part3-next` / `part4-next` postMessage. 4장의 조건 문구·출처는 `part4.html`의 `C` 배열, 효과는 `E` 배열(조건→효과 연결은 **팀의 해석**이며, 출처마다 `원문 직접 확인 / 검색 결과 기반 / 기억 기반 / 2차 출처 / 미확인`을 표시. 오하이오 법안은 발의 단계·법안 번호 미확인, 사회/집단 소속은 뚜렷한 출처 없음).


**결과 화면의 철학자 카드** (`index.html`의 `PHIL`): 판단 유형(OO/OX/XO/XX)마다 같은 생각을 한 철학자의 문장을 보여준다. OO 데닛(원문 일부 확인), OX 대너허 ‘응보의 틈’(초록 확인), XO 영 ‘사회적 연결 모델’(위키백과 요약 경유, 인용 아님), XX 브라이슨(초록 확인). 번역은 우리가 한 것이라 원문을 함께 표기. 크레딧은 약 6.5초 뒤 처음으로 돌아간다.
